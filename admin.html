Questa pagina è solo per te. Importante: apri sempre admin.html tramite un server (il sito pubblicato su GitHub Pages va benissimo, oppure in locale con python3 -m http.server dentro la cartella del progetto) — se lo apri con un doppio click diretto dal computer, il browser blocca la lettura dei file dentro data/ e i pannelli qui sotto restano vuoti.

1. Impostazioni lega

Nome, stagione, data asta, le due password (guest = vede solo il sito, admin = vede il sito E questa pagina) e la chiave API — e qui sotto i nomi dei fantallenatori, modificabili senza toccare config.json a mano. Lascia vuoto un campo password se non vuoi cambiarla. Puoi aggiungere o togliere fantallenatori con i pulsanti.

Il token GitHub per il salvataggio diretto non va mai messo qui (repository pubblico: GitHub lo revocherebbe da solo appena lo trovasse in un file). Si incolla direttamente nel browser, resta solo per questa sessione della scheda.

Controlla le associazioni proposte prima di generare il file — funziona con i ruoli classici P/D/C/A.

5. Calendario di lega

Chi affronta chi ogni giornata nella VOSTRA lega (non le partite reali di Serie A). Importante: il numero di giornata deve corrispondere a quello REALE del campionato di Serie A, non a un vostro contatore che parte da 1 — nel vostro caso, facendo l'asta il 15 settembre e saltando le prime 4 giornate, la vostra prima giornata di lega corrisponderà a una giornata reale già in corso (la 5ª circa), non alla "giornata 1". Se hai già inserito la chiave API in config.json, qui sotto te lo suggerisco in automatico.
